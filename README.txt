ZION ASSEMBLY WEBSITE

1. Upload index.html, style.css and script.js to your GitHub repository.
2. Create folders named assets and sermons.
3. Put a hero image at assets/hero.jpg.
4. Put your sermon PDF files inside sermons/.
5. Edit the sermon list in script.js so the titles, dates and filenames match your files.
6. Commit the changes. GitHub Pages will publish the updated website.

The contact email in index.html is a placeholder. Replace it with the church's real email.
